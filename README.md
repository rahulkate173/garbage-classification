# Garbage Classification

A machine learning project for classifying waste items from images into categories like cardboard, glass, metal, paper, plastic, and trash using deep learning models such as CNNs.

Developed by Rahul Kate, a machine learning enthusiast from Pune, India.

## Features

- Image-based waste classification for recycling support.
- Built with Python, TensorFlow/Keras or PyTorch for model training.
- Compatible with popular datasets like TrashNet.
- Potential for real-time inference and deployment.

## Dataset

Uses the Garbage Classification dataset with ~2,500 images across 6 classes:
- Cardboard: 393 images
- Glass: 491 images
- Metal: 400 images
- Paper: 584 images
- Plastic: 472 images
- Trash: 127 images

Download from Kaggle or TrashNet repository.
